## What We Changed

Six changes were implemented directly in the codebase, each driven by a specific user entry from the form above.

### Change 1 — Wallet Detection Performance (FB-PERF-01)

**Triggered by**: Kavya Sundaram (⭐⭐⭐⭐⭐, 19 Sep 2026) — *"Great overall experience."* combined with her reported session lag issue during testing.

**Root cause identified**: Multiple concurrent React hooks each fired the full `window.midnight` detection cycle (1200 ms polling) independently, causing visible freezes when opening the connect modal.

**What changed**:
- Implemented a singleton `detectionPromise` in `frontend/lib/one-am-wallet-adapter.ts` — all hooks share one detection run.
- Polling timeout reduced from **1200 ms → 350 ms** (sampled every 40 ms).
- Added a 3-second `AbortController` to every `fetch()` call in `frontend/lib/api-client.ts`.

```diff
// frontend/lib/one-am-wallet-adapter.ts
- const detected = await detectWallet(1200); // no dedup, 1.2s
+ if (!this.detectionPromise) {
+   this.detectionPromise = detectWallet(350); // singleton, 350ms
+ }
+ const detected = await this.detectionPromise;
```

**Files**: `frontend/lib/one-am-wallet-adapter.ts`, `frontend/lib/api-client.ts`

### Change 3 — Default Network Set to Preprod (FB-NET-03)

**Triggered by**: Ishaan Nair (⭐⭐⭐⭐⭐, 20 Sep 2026) — *"Very easy to use and understand."* — during testing found the connect dialog defaulted to Preview, causing immediate network mismatch alerts on Preprod.

**What changed**:
- `DEFAULT_NETWORK` set to `'preprod'` across `OneAMWalletAdapter`, `WalletConnectModal`, and the `useMidnightWallet` hook.
- Preprod contract address hardcoded as the primary target.

```diff
- const DEFAULT_NETWORK = 'preview';
+ const DEFAULT_NETWORK = 'preprod';
```

### Change 4 — Session Persistence Across Page Navigation (FB-SESS-04)

**Triggered by**: Rohan Chhabra (⭐⭐⭐⭐, 20 Sep 2026) — navigating between pages dropped the wallet session to disconnected, forcing reconnection each time.

**What changed**:
- `localStorage.setItem('cyphra_wallet_connected', '1am' | 'demo')` written on successful connect.
- On page mount, wallet hook reads this key and auto-restores without a second user action.
- Activity feed cached under `cyphra_activity_${walletAddress}` for offline-resilient loading.

```diff
// one-am-wallet-adapter.ts
  async connect() {
    const api = await this.detectionPromise;
+   localStorage.setItem('cyphra_wallet_connected', '1am');
    return api;
  }
+ async restoreSession() {
+   const saved = localStorage.getItem('cyphra_wallet_connected');
+   if (saved === '1am') return this.connect();
+   if (saved === 'demo') return this.loadDemoAccount();
+ }
```

**Files**: `frontend/lib/one-am-wallet-adapter.ts`, `frontend/lib/api-client.ts`
