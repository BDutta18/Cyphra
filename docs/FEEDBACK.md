## What We Changed

The following changes were implemented directly in the codebase as a result of the above feedback. Each change is traceable to a specific feedback item.

---

### Change 1 — Wallet Connection Performance Fix (FB-PERF-01)

**Feedback driver**: Kavya Sundaram — *"Connecting 1AM Wallet was lagging heavily due to multiple repetitive polling loops"* (Theme 3, above)

**What we changed**:
- Implemented a singleton `detectionPromise` in `frontend/lib/one-am-wallet-adapter.ts` to deduplicate concurrent wallet detection calls.
- Cached the `initialApi` reference directly from `window.midnight` for 0 ms retrieval.
- Reduced the DOM polling timeout from **1200 ms to 350 ms** (sampling every 40 ms).
- Added a 3-second `AbortController` timeout to all remote fetch calls in `frontend/lib/api-client.ts`.

**Files modified**:
```
frontend/lib/one-am-wallet-adapter.ts   ← singleton detectionPromise, 350ms timeout
frontend/lib/api-client.ts              ← AbortController(3000) on all fetch()
```

**Before / After**:
```diff
// frontend/lib/one-am-wallet-adapter.ts  (simplified diff)
- const detected = await detectWallet(1200);  // 1.2 s polling, no dedup
+ if (!this.detectionPromise) {
+   this.detectionPromise = detectWallet(350); // singleton, 350 ms
+ }
+ const detected = await this.detectionPromise;
```

**Feedback driver**: Aditi Deshpande — *"Reviewers who do not have the 1AM Chrome extension should not be blocked"* (Theme 3, above)

### Change 4 — Session Persistence Across Page Navigations (FB-SESS-04)

**Feedback driver**: Rohan Chhabra — *"Navigating between pages disconnected the active wallet session"* (Theme 3, above)

**What we changed**:
- Wrote `'1am'` or `'demo'` to `localStorage.setItem('cyphra_wallet_connected', ...)` on successful connection.
- On page mount, the wallet hook reads this key and auto-reconnects without a second user click.
- Activity history is also cached in `localStorage` under `cyphra_activity_${walletAddress}` to survive offline/reload.

**Files modified**:
```
frontend/lib/one-am-wallet-adapter.ts   ← localStorage write on connect
frontend/lib/api-client.ts              ← localStorage cache for activity
```

**Before / After**:
```diff
// one-am-wallet-adapter.ts
  async connect() {
    const api = await this.detectionPromise;
+   localStorage.setItem('cyphra_wallet_connected', '1am');
    return api;
  }
+ async restoreSession() {
+   const saved = localStorage.getItem('cyphra_wallet_connected');
+   if (saved === '1am') return this.connect();
+   if (saved === 'demo') return this.loadDemoAccount();
+ }
```

### Change 5 — Improved Address Validation (FB-VAL-05)

**Feedback driver**: Priya Patel — *"Preprod Bech32 address format was rejected by older validation regex"* (from user.md Section 3 resolution matrix)

**What we changed**:
- Expanded the address validation regex to `/^mn_addr_preprod1[0-9a-z]{58,}$/` across all three validation layers.
- Added real-time inline validation with green tick / red error badge in the Send UI.

**Files modified**:
```
shared/src/schemas/index.ts       ← updated Zod validation regex
frontend/app/send/page.tsx        ← real-time validation badge
backend/src/utils/crypto.ts       ← server-side validation consistency
```
