## 2. Compact Smart Contract & Compiler Toolchain

The CYPHRA contract is written in Compact, Midnight's domain-specific language for privacy-preserving zero-knowledge smart contracts.

- **Compact Compiler Version**: `0.31.1` (official release targeting Midnight Ledger 8.0 Preprod)
- **Compact CLI**: `compact 0.5.2`
- **Language Pragma**: `pragma language_version >= 0.23;`

### Zero-Knowledge Circuits
1. **`deposit(amount, noteCommitment)`**: Converts unshielded NIGHT into private note commitments on-chain.
2. **`confidentialTransfer(nullifier, newCommitment, changeCommitment)`**: Spends an existing note commitment via nullifier, generating confidential recipient and change notes with ZK balance conservation proof ($input = output + change$).
3. **`registerPaymentRequest(requestId, requestCommitment)`**: Registers private payment requests on-chain using opaque hashes.
4. **`fulfillPaymentRequest(requestId, paymentNullifier, receiptCommitment)`**: Confidentially fulfills a payment request.
5. **`grantAuditorAccess(auditorKey, permissions)`**: Enables selective disclosure to compliance auditors.
6. **`revokeAuditorAccess(auditorKey)`**: Revokes auditor viewing permissions.

### Generated Artifacts (`contracts/cyphra/src/managed/`)
- **`contract/`**: TypeScript and JavaScript bindings (`index.d.ts`, `index.js`, `index.js.map`).
- **`keys/`**: 12 Prover (`.prover`) and Verifier (`.verifier`) cryptographic keys.
- **`zkir/`**: 12 Zero-Knowledge Intermediate Representation binary (`.bzkir`) and circuit (`.zkir`) definitions.
- **`compiler/`**: Compilation metadata.

### Setting Up the Deployment Environment

1. Start the Midnight proof server (Docker):
   ```bash
   docker run -p 6300:6300 midnightntwrk/proof-server:latest -- midnight-proof-server -v
   ```

2. Export the secure deployment credentials in your terminal session:
   ```bash
   # Windows PowerShell
   $env:MIDNIGHT_NETWORK="preprod"
   $env:MIDNIGHT_WALLET_SEED="your secret 24-word seed phrase"
   $env:MIDNIGHT_DEPLOYER_ADDRESS="mn_addr_preprod1ccryaa8je09fvvz0ktyxx4ns79fqhcddnxvpf2jlk4l6qyq78e4sl8lkxl"

   # Linux / macOS / WSL
   export MIDNIGHT_NETWORK="preprod"
   export MIDNIGHT_WALLET_SEED="your secret 24-word seed phrase"
   export MIDNIGHT_DEPLOYER_ADDRESS="mn_addr_preprod1ccryaa8je09fvvz0ktyxx4ns79fqhcddnxvpf2jlk4l6qyq78e4sl8lkxl"
   ```

3. Compile the Compact contract:
   ```bash
   pnpm --filter @cyphra/contracts run compact:compile
   # or on Windows using WSL:
   pnpm --filter @cyphra/contracts run compact:compile:wsl
   ```

4. Deploy the contract to Midnight Preprod:
   ```bash
   pnpm --filter @cyphra/contracts run deploy:preprod
   ```

5. Once finalized, set the resulting 64-hex contract address in your environment:
   ```bash
   CONTRACT_ADDRESS=<64-hex-address>
   NEXT_PUBLIC_CYPHRA_CONTRACT_ADDRESS=<64-hex-address>
   ```

## 4. End-to-End Payment Flow on Preprod

1. **1AM Wallet Connection**:
   - The user opens CYPHRA in their browser with the 1AM Wallet extension installed.
   - 1AM Wallet is configured to the **Preprod** network.
   - User approves the connection prompt.

2. **Private Balance & Shielded Deposit**:
   - User inputs an amount of unshielded NIGHT to deposit.
   - 1AM Wallet generates a cryptographic note commitment and proves the deposit circuit off-chain.
   - The unshielded funds are wrapped into a private note commitment on the Preprod ledger.

3. **Confidential Transfer**:
   - User specifies recipient's Midnight address (`mn_shielded1...` or `mn_addr_preprod1...`).
   - 1AM Wallet WASM prover evaluates value conservation ($input = output + change$).
   - Note commitment is spent via nullifier on-chain without disclosing sender, recipient, or amount.

4. **Payment Requests & QR Invoicing**:
   - Merchant creates payment request (`cyphra:pay?...`).
   - Payer scans QR code or opens payment link.
   - 1AM Wallet settles request on Midnight Preprod with cryptographic fulfillment receipt.
